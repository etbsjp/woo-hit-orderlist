特定の商品を注文した方の中から抽選で当選者を選び、注文メモ経由でメッセージを送信できる WooCommerce 用プラグインです。

== Description ==

抽選販売の当選通知を想定したプラグインです。商品・期間・注文ステータスで注文を絞り込み、その中から無作為に当選者を選んで、注文メモでメッセージを送れます。

= できること =

* **WooCommerce > 注文検索** … 商品・期間・注文ステータスで注文を絞り込み、一覧を XLSX で書き出せます。
* **ランダムチェック** … 当選人数を指定して、対象の注文から無作為に選びます。
* **メール送信** … 選んだ注文に「顧客へのメモ」を追加します（注文者にメールが届きます）。
* **WooCommerce > 注文メモ検索** … 送信済みの注文メモをキーワードと期間で検索できます。

商品に「抽選購入」タグを付けると、検索で絞り込みやすくなり、商品ページのボタンが「抽選に申し込む」に変わります。タグを付けるかどうかは任意です。

= ご注意 =

* 送信されるのは「顧客へのメモ」です。**そのまま注文者にメールが届きます。** 文面を確認してから送信してください。
* 送信は取り消せません。
* 同じ商品が1つの注文の中で複数明細に分かれていても、1注文1行として扱われます（当選確率が偏らないようにするためです）。

= 動作環境 =

* WooCommerce（HPOS・レガシーのどちらの注文保存方式にも対応しています）
* PHP 7.4 以上

WordPress のバージョン下限は設けていません。本プラグインが使用する WordPress の機能は、いずれも古くから提供されているものです。

== Changelog ==

* [ 機能追加 ] テーマに古いバージョンのコードが残っている場合に、管理画面へ警告を表示するようにしました。
* [ 不具合修正 ] テーマに古いバージョンのコードが残っているサイトで、プラグインを有効化できない不具合を修正しました。これまでは「重大なエラー」と表示され、有効化が取り消されていました。
* [ セキュリティ修正 ] テーマに古いバージョンのコードが残っているサイトで、当選メール送信が確認処理を通らずに実行できる状態になっていた問題に対処しました。プラグイン側の確認処理が先に働くようにしていますが、テーマから古いコードを取り除くまで完全には塞がりません。

= 1.1.4 =
* [ 不具合修正 ] 抽選購入タグを付けていない商品のボタン文言が、すべて「カートに入れる」に上書きされる不具合を修正しました。バリエーション商品は「オプションを選択」、在庫切れの商品は「続きを読む」のように、WooCommerce 本来の文言が表示されます。これまではバリエーションを選ばないとカートに入らない商品にも「カートに入れる」と表示されていました。
* [ 不具合修正 ] 他のプラグインが設定したボタン文言も上書きしてしまう問題を解消しました。抽選購入タグを付けていない商品では、他のプラグインの文言がそのまま表示されます。
* [ その他 ] 上記にともない、抽選購入タグを付けていない通常商品のボタン文言は、これまでの固定表示「カートに入れる」から、お使いのサイトの WooCommerce の表示にしたがうようになりました。表示される文言がこれまでと変わる場合があります。

= 1.1.3 =
* [ 不具合修正 ] 商品タグを付けていない商品の商品ページが表示できない不具合を修正しました。タグを付けていない商品があるショップでは、その商品ページがエラー画面になっていました。
* [ 不具合修正 ] ブロックで商品を並べているページや商品一覧ページで、商品が表示されない不具合を修正しました。商品ごとのボタン文言を決める処理が、商品の情報を受け取れずにエラーになっていたためです。
* [ その他 ] 「抽選購入」タグの判定を、タグ名の完全一致で行うようにしました。これまでは部分一致だったため、「抽選購入不可」のようなタグ名でも抽選用のボタン文言に変わっていました。

= 1.1.2 =
* [ 不具合修正 ] テーマ側に同じ名前の仕組みがあるサイトで、プラグインを有効化すると画面が表示できなくなる不具合を修正しました。
* [ 不具合修正 ] 当選人数に候補の件数より大きい数・0・小数を入力すると、処理が終わらなくなる不具合を修正しました。入力が正しくないときはメッセージを表示して中止します。
* [ 不具合修正 ] 見覚えのない注文ステータスがあるときに、管理画面に警告が表示される不具合を修正しました。
* [ 不具合修正 ] WooCommerce を停止した状態でメール送信を実行するとエラーになる問題を修正しました。あわせて、送信に失敗したときは画面にその旨を表示するようにしました。これまでは失敗してもチェックが外れるため、送信できたように見えていました。

* [ 対応環境 ] WooCommerce の「高パフォーマンス注文保存（HPOS）」に対応しました。これまでは HPOS を有効にしたサイトで、注文の検索結果が常に0件になっていました。
* [ 機能追加 ] ダッシュボードに使い方と注意事項のウィジェットを追加し、プラグイン一覧の行と専用画面にサポートへの導線を追加しました。
* [ その他 ] 外部サイトから読み込んでいたファイルを同梱に変更しました。外部への通信を禁止している環境でも動作します。

# Woo Hit Orderlist

特定の商品を注文した方の中から抽選で当選者を選び、注文メモ経由でメッセージを送信できる WooCommerce 用プラグインです。抽選販売の当選通知を想定しています。

## できる事

- **WooCommerce > 注文検索** … 商品・期間・注文ステータスで注文を絞り込み、一覧を XLSX で書き出せます
- **ランダムチェック** … 当選人数を指定して、対象の注文から無作為に選びます
- **メール送信** … 選んだ注文に「顧客へのメモ」を追加します（注文者にメールが届きます）
- **WooCommerce > 注文メモ検索** … 送信済みの注文メモをキーワードと期間で検索できます

商品に「抽選購入」タグを付けると、検索で絞り込みやすくなり、商品ページのボタンが「抽選に申し込む」に変わります。

## 注意事項

- 送信されるのは「顧客へのメモ」です。**そのまま注文者にメールが届きます。** 文面を確認してから送信してください
- 送信は取り消せません
- 同じ商品が1つの注文の中で複数明細に分かれていても、**1注文1行**として扱われます（当選確率が偏らないようにするため）

## 動作環境

- WordPress 6.7 以上
- WooCommerce（HPOS・レガシーのどちらの注文保存方式にも対応）
